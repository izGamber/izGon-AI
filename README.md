## 🎯 Šta Radi?

izGon AI rešava problem koji svi AI korisnici imaju:

**Svaki put kada resetuješ sesiju, gube se kontekst i memorija prethodnog rada.**

Sa izGon AI:
✅ AI se seća šta si radio  
✅ Seć se konteksta i ciljeva  
✅ Nastavi rad bez resetovanja  
✅ Radi sa bilo kojim AI modelom  

## ✨ Glavne Karakteristike

- 🧠 **Brain Engine** - Inteligentno čuvanje memorija AI sesija
- 💾 **Memorija sa prioritetima** - Označi važne stavke (1-5)
- 📸 **Snapshots** - Spremi stanja rada u sekundi
- 🔍 **Pretraga** - Pronađi šta trebaš trenutno
- 🎨 **Dashboard** - Moderni, responsive, dark mode
- 🔄 **Multi-AI** - Radi sa GPT-4, Claude, Gemini...
- ⚙️ **Postavke** - Kontrola nad svim

## 🚀 Brzi Start

```bash
# 1. Kloniraj
git clone https://github.com/izGamber/izGon-AI.git
cd izGon-AI

# 2. Instaliraj
pip install -r requirements.txt

# 3. Pokreni
# Windows
run.bat

# Linux/Mac
./run.sh

# Docker
docker-compose up -d
```

**Otvori:** (http://127.0.0.1:8000/)
